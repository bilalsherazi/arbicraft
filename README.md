# Arbicraft

A modern Next.js web application inspired by Arbicraft, built with scalability, performance, and user experience in mind.

## Features

- Responsive design
- Modern UI/UX
- Next.js App Router
- Reusable components
- SEO-friendly architecture
- Fast loading performance

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Installation

npm install

npm run dev
